## 🧭 How I Work

**01 · Product first** — start from what the user is trying to accomplish, then decide what the interface and data model need to be.
**02 · Architecture that survives** — clear boundaries between UI, data access and business logic, so the second feature isn't harder than the first.
**03 · Finished, not just working** — loading, empty and error states, keyboard access and mobile layout are part of the build, not a later pass.
